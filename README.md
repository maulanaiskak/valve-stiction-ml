# valve-stiction-ml

Training pipeline for the valve stiction detection classifier — the V3 "bounded ML comparison" component of the [Valve Stiction Fault Detection distributed IoT pipeline](https://github.com/) project. Rebuilds the ML side of an undergraduate thesis (custom Random Forest on hand-rolled time-series features) as a reproducible, tested, production-shaped training project.

See [docs/ML_PLAN.md](docs/ML_PLAN.md) for the full plan: data strategy, preprocessing, feature engineering, model selection, and evaluation methodology, plus open questions.

Status: planning stage — no training code yet.
